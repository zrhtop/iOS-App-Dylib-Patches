使用说明

第一次设置只需几步。

01

开启 GitHub Pages

前往仓库 Settings → Pages → Deploy from a branch，选择 main 和 /docs 并保存。

打开 Pages 设置 ↗
02

创建最小权限访问令牌

在 GitHub Fine-grained tokens 中，只选择本仓库，授予 Contents: Read and write。不要给其他仓库授权。

创建访问令牌 ↗
03

连接并添加 IPA

网页只在本次会话使用令牌。可上传较小 IPA；较大 IPA 请先发布到本仓库 Releases，再使用其公开下载链接。

04

添加到 AltStore

在 AltStore Classic 的 Sources 页面点击 +，粘贴软件源 URL。新版本排在第一位，AltStore 才会优先识别更新。

安全提醒

公开仓库中的 IPA 和软件源任何人都可以访问。本页面不能提供私有下载。请仅发布你有权分发的 IPA，勿上传含账号、设备标识或私有证书的文件。
